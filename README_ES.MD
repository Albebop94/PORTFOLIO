# 🇪🇸 Portfolio & Master Workspace

Bienvenido a mi **Portfolio Profesional**. Soy un Ingeniero DevOps y Sysadmin Senior con más de 10 años de experiencia, especializado en construir, mantener y automatizar infraestructuras robustas y sistemas de software de alta disponibilidad.

Mi perfil actúa como puente entre operaciones en Bare-Metal (Sysadmin, Proxmox, KVM en Alta Disponibilidad), Arquitectura Cloud (Google Cloud Platform, AWS) e Ingeniería de Software (Python, Clean Architecture, Domain-Driven Design). Este repositorio actúa como hub central uniendo varios proyectos y Pruebas de Concepto (PoCs) que demuestran mi conjunto de habilidades.

## Estructura de Proyectos

El espacio principal está organizado en dominios de conocimiento claros:

- **`infrastructure/`**: Infraestructura como código (IaC), implementaciones KVM/Proxmox, scripts de aprovisionamiento en GCP (Terraform) y automatización con Ansible.
- **`backend/`**: Proyectos de ingeniería de software orientados a APIs REST/gRPC usando Python, FastAPI, SQLAlchemy siguiendo principios de DDD (Domain-Driven Design) y Arquitectura Limpia.
- **`devops/`**: Pipelines automatizados CI/CD, observabilidad (Prometheus, Grafana) y orquestación de contenedores (Docker/K8s).
- **`architectures/`**: Despliegues globales, configuraciones de HAProxy, Balanceadores de Carga, API Gateways y colas de mensajes (RabbitMQ).
- **`frontend/`**: Futuros proyectos web, blogs o interfaces de usuario.
- **`docs/`**: Documentación pública transversal.

*Principios aplicados en todos los repositorios: Enfoque Multirepo | Versionado Semántico | Conventional Commits | Código Limpio | Alta Disponibilidad (HA) por diseño.*
